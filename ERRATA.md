# AI Engineering — Errata

This is the controlled errata register for *AI Engineering: From Foundations to Production Systems — Code-Verified Illustrated Study Edition (2026)* by Stanley Osei-Wusu.

## Current status

No confirmed post-publication errata are recorded for the v3.13 publication-infrastructure candidate.

## Reporting a suspected error

Please open a GitHub issue in this repository and include:

- book version/edition;
- print page or EPUB chapter/section;
- the exact sentence, code block, equation, figure, or output involved;
- what you believe is incorrect;
- reproducible evidence where the issue concerns code or software behavior;
- environment/library versions where relevant.

A report is not an erratum until it has been reproduced or editorially verified. Confirmed corrections will be recorded here with the affected version, disposition, and first corrected version.

## Classification

- **Technical erratum** — incorrect technical statement, equation, code, output, figure, or procedure.
- **Production erratum** — layout, cross-reference, navigation, or rendering defect.
- **Currency note** — originally correct material affected by later API/library/platform changes; not treated as an original-book error.
- **Clarification** — wording improved without changing the underlying claim.
